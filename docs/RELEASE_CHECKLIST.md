- [ ] Real Backend authentication and upload (`PENDING_REAL_ACCOUNT` / `PENDING_BACKEND_CONTRACT`)

Keep the following facts separate in every handoff:

```text
Source Backup = Git commit + pushed branch
GitHub Release = tag + release notes + APK asset
Production Deployment = server deployment and health/API/site verification
Store Release = app store publication
```
